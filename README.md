## 平台约定

常规 2D 应用每眼内容区为 640×480，左右双目同显，物理逻辑输出 1280×480。视频和游戏需要在渲染路径中处理同一帧的双眼输出。使用镜腿与手柄操作，避免依赖手机触屏布局。
